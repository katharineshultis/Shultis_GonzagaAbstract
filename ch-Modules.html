    Chapter 20 What is a Module?

    Objectives: The learning outcomes for this chapter are to...

    • ...understand the definition of a module.
      🔗
      🔗
    • ...be able to give several examples of modules.
      🔗
      🔗
    🔗
    The way I think of a module is that it’s exactly like a vector space, except over a ring instead of a field. However, if you’re not confident you’ve got the axioms of a vector space right, this poses an issue. Informally, the key to vector spaces is that we can add vectors together, and we can scale them by our constants, which come from a field (frequently \(\R\) in your past courses as early introductions typically happen in Calculus and Linear Algebra courses). Also, things work “nicely” or “as expected.” Here’s a more formal definition of a module. If you’d like a formal definition of a vector space, replace the ring below with a field.
    🔗

    Definition 20.0.1.

    Let \((R,+_{R},\cdot)\) be a ring and \((M,+_{M})\) an abelian group. We say \(M\) is a left \(R\)-module (or just a left module if the ring in question is clear) if there is a function \(\mu:R\times M\to M\) typically denoted as \(\mu(r,m)=rm\) for all \(r\in R\) and \(m\in M\) such that the following properties hold:
    (A)
    🔗
    A sort of “associative property” holds. For all \(r,s\in R\) and \(m\in M\text{,}\) we have \(r(sm)=(r\cdot s)m\text{.}\)
    🔗
    (D)
    🔗
    Two sort of “distributive properties” hold. For all \(r,s\in R\) and \(m,n\in M\text{,}\) we have
    \begin{equation*} (r+_{R}s)m=rm+_{M}sm \end{equation*}
    and
    \begin{equation*} r(m+_{M}n)=rm+_{M}rn. \end{equation*}
    🔗
    If \(R\) has an identity, denoted \(1\text{,}\) then we also require that the identity satisfies
    \begin{equation*} 1m=m \end{equation*}
    for all \(m\in M\text{.}\)
    🔗
    🔗

    Remark 20.0.2.

    We could also define a right \(R\)-module with a function \(\nu:M\times R\to M\) by insisting instead that \(m(r\cdot s)=(mr)s\text{,}\) \((m+_{M}n)s=ms+_{M}ns\text{,}\) and \(m(r+_{R}s)=mr+_{M}ms\text{.}\) Note that an abelian group could simultaneously be a left \(R\)-module and a right \(S\)-module. As long as these two module structures are compatible, we call this an \(R\)-\(S\)-bimodule. I currently have zero intention to discuss bimodules further than this awkward remark.
    🔗
    🔗

    Remark 20.0.3.

    If \(R\) is a commutative ring, then every left \(R\)-module is automatically a right module as well via \(\nu(m,r)=rm=\mu(r,m)\text{,}\) and so we drop the left/right distinction and simply refer to \(R\)-modules when \(R\) is commutative.
    🔗
    🔗

    Example 20.0.4.

    Any ring, \(R\text{,}\) is both a left and right \(R\)-module. Why?
    🔗
    🔗

    Example 20.0.5.

    Consider the (commutative) ring \(R=\R\) and abelian group (under addition) \(M=\R[X]\text{.}\) We have that \(M\) is an \(R\)-module. Indeed, for any \(r\in R\) and \(m\in M\text{,}\) we know that \(r\) is a real number and \(m\) is a polynomial in \(X\) with real coefficients. The module action \(\mu:R\times M\to M\) is given by the multiplication \(\mu(r,m)=rm\) where we think of \(r\) as a linear polynomial. What else needs to be shown?
    🔗
    🔗

    Example 20.0.6.

    Let \(R\) be a ring and \(I\) a left ideal of \(R\text{.}\) Then \(I\) is a left \(R\)-module. Is this clear?
    🔗
    🔗

    Example 20.0.7.

    Let \((G,+)\) be an abelian group. Then \(G\) is a \(\Z\)-module. Is this clear?
    🔗
    🔗

    Example 20.0.8.

    Let \(R\) be a commutative ring and \(I\) an ideal of \(R\text{.}\) Then \(R/I\) is an \(R\)-module. Indeed, we can define the function \(\mu\) via
    \begin{gather*} \mu(r,a+I)=ra+I, \text{ i.e. }r({a}+I)=(ra)+I\text{ for }r\in R,~a+I\in R/I. \end{gather*}
    Should we check this is well-defined, or is that clear? With this function in place, we can show the required properties:
    (A)
    🔗
    For \(r,s\in R\) and \(a+I\in R/I\text{,}\) we have
    \begin{align*} r(s(a+I))&=r((sa)+I)\\ &=r(sa)+I\\ &=(rs)a+I\\ &=(rs)(a+I). \end{align*}
    🔗
    (D)
    🔗
    For \(r,s\in R\) and \(a+I,b+I\in R/I\text{,}\) we have
    \begin{align*} (r+s)(a+I)&=((r+s)a)+I\\ &=(ra+sa)+I\\ &=(ra+I)+(sa+I) \end{align*}
    and
    \begin{align*} r((a+I)+(b+I))&=r((a+b)+I)\\ &=(r(a+b))+I\\ &=(ra+rb)+I\\ &=(ra+I)+(rb+I). \end{align*}
    🔗
    🔗
    🔗

    Exercises Exercises

    20.A.

    Complete the missing parts above. They’re listed below to help you out!
    🔗
    1. Explain why, for any ring \(R\text{,}\) \(R\) is both a left and right \(R\)-module.
      🔗
      🔗
    2. Fill in the missing details to show that \(\R[X]\) is an \(\R\)-module. Note that as \(\R\) is a field, this should mean that \(\R[X]\) is a \(\R\)-vector space! What’s the vector space dimension?
      🔗
      🔗
    3. Show that for any left ideal \(I\) of any ring \(R\text{,}\) \(I\) is a left \(R\)-module.
      🔗
      🔗
    4. Show that every abelian group \(G\) is a \(\Z\)-module.
      🔗
      🔗
    🔗

    20.B.

    Here are some basic properties of modules. For each, let \(R\) be a ring with identity, and \(M\) a left \(R\)-module.
    🔗
    1. Show that \(0m=0\) and \((-1)m=-m\) for all \(m\in M\text{.}\)
      🔗
      🔗
    2. Assume that \(rm=0\) for some \(r\in R\) and \(m\in M\setminus\{0\}\text{.}\) Prove that \(r\) does not have a left inverse, i.e. there is no element \(s\in R\) such that \(sr=1\text{.}\)
      🔗
      🔗
