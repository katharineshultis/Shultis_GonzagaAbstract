    Chapter 22 Module Modules and Module Homomorphisms

    Objectives: The learning outcomes for this chapter are to...

    • ...understand the definition of a module homomorphism.
      🔗
      🔗
    • ...understand the definition of a quotient module.
      🔗
      🔗
    • ...be able to give several examples of module homomorphisms and quotient modules.
      🔗
      🔗
    🔗
    Let’s start by pointing out that quotient modules are “easy” (relatively speaking). Let \(R\) be a ring, \(M\) a left \(R\)-module, and \(N\) a left \(R\)-submodule of \(M\text{.}\) Momentarily ignoring the module structure, since \(M\) is an abelian group, it is necessarily the case that \(N\) is a normal subgroup of \(M\text{,}\) so \(M/N\) is a group as well. Now, we only need to know how to consider \(M/N\) as an \(R\)-module! The “obvious” choice is to define \(r(m+N)=(rm)+N\) for any \(r\in R\) and \(m+N\in M/N\text{.}\) It turns out that this works nicely for us. Indeed, we can (and maybe you should) check that the module properties check out.
    🔗
    It’s worth noting that the function \(\mu:R\times M\to M\) is often called the module action. It’s possible we’ve already used this terminology some, and this paragraph should be moved into chapter 20 or 21.
    🔗

    Example 22.0.1.

    We know that \(\Z\) is a ring and can show that \(\Z[x,y]\) is a \(\Z\)-module. Note that the elements of \(\Z[x,y]/(x^{2},xy)\) look like
    \begin{equation*} a_{0} + by + a_{1}y+a_{2}y^{2}+\cdots+a_{k}y^{k} + (x^{2},xy) \end{equation*}
    for any \(b,a_{i}\in \Z\) and \(k\in\N\text{.}\) We can consider this quotient group as a \(\Z\)-module under the action:
    \begin{gather*} n(a_{0} + by + a_{1}y+a_{2}y^{2}+\cdots+a_{k}y^{k} + (x^{2},xy))\\ =na_{0} + nby + na_{1}y+na_{2}y^{2}+\cdots+na_{k}y^{k} + (x^{2},xy) \end{gather*}
    and under this action, we have that \(\Z[x,y]/(x^{2},xy)\) is a \(\Z\)-module.
    🔗
    🔗
    That’s about all I want to say on quotient modules for now, so let’s move on to the definition of a module homomorphism:
    🔗

    Definition 22.0.2.

    Let \(R\) be a ring and \(M,N\) left \(R\)-modules (with the operation written as addition). A function \(\varphi:M\to N\) is a left \(R\)-module homomorphism (or with fewer adjectives on the noun “homomorphism” when it’s clear what type of homomorphism we’re discussing) if for every \(m,m'\in M\) and \(r\in R\text{,}\)
    \begin{equation*} \varphi(m+m')=\varphi(m)+\varphi(m') \end{equation*}
    and
    \begin{equation*} \varphi(rm)=r\varphi(m). \end{equation*}
    🔗
    🔗

    Remark 22.0.3.

    Notice that this looks very similar to the notion of a “linear” function in linear algebra. That should come as no surprise as modules are really just vector spaces over a general ring (instead of over a field)!
    🔗
    🔗

    Example 22.0.4.

    Let \(R\) be a ring and \(I\) an ideal of \(R\text{.}\) Then recall that \(R\) and \(R/I\) are both left \(R\)-modules and note that the function \(p:R\to R/I\) given by \(r\mapsto r+I\) is a surjective \(R\)-module homomorphism. What needs to be done to show this?
    🔗
    🔗

    Example 22.0.5.

    Let \(R\) be a ring and \(I\) an ideal of \(R\text{.}\) Recall that \(I\) and \(R\) are both left \(R\)-modules and note that the function \(\iota:I\to R\) given by \(a\mapsto a\) is an injective \(R\)-module homomorphism. What needs to be done to show this?
    🔗
    🔗
    Just as in ring and group lands, we can define the kernel and image of module homomorphisms:
    🔗

    Definition 22.0.6.

    Let \(R\) be a ring, \(M\) and \(N\) left \(R\)-modules and \(\varphi:M\to N\) a left \(R\)-module homomorphism. Then, the kernel of \(\varphi\) is
    \begin{equation*} \ker(\varphi)=\{m\in M\mid \varphi(m)=0_{N}\} \end{equation*}
    and the image of \(\varphi\) is
    \begin{equation*} \operatorname{im}(\varphi)=\varphi(M)=\{\varphi(m)\mid m\in M\}=\{n\in N\mid n=\varphi(m)\text{ for some }m\in M\}. \end{equation*}
    🔗
    🔗
    It should come as no surprise (I hope!) that the three Isomorphism Theorems have analogues in module land! We will not necessarily prove these; however, it should be noted that the proofs are similar to those we’ve already done!
    🔗

    Theorem 22.0.7. First Isomorphism Theorem for Modules.

    Let \(R\) be a ring, \(M\) and \(N\) left \(R\)-modules, and \(\varphi:M\to N\) a left \(R\)-module homomorphism. Then, \(\ker(\varphi)\) is a submodule of \(M\text{,}\) \(\operatorname{im}(\varphi)\) is a submodule of \(N\text{,}\) and
    \begin{equation*} M/\ker(\varphi)\cong \operatorname{im}(\varphi). \end{equation*}
    🔗
    🔗

    Theorem 22.0.8. Second Isomorphism Theorem for Modules.

    Let \(R\) be a ring, \(M\) a left \(R\)-module and \(N,K\) submodules of \(M\text{.}\) Let \(K+N\) denote the subset \(\{k+n\mid k\in K,n\in N\}\) of \(M\text{.}\) Then \(K+N\) is a submodule of \(M\text{,}\) \(N\) is a submodule of \(K+N\text{,}\) \(K\cap N\) is a submodule of \(K\text{,}\) and
    \begin{equation*} (K+N)/N\cong K/(K\cap N). \end{equation*}
    🔗
    🔗

    Theorem 22.0.9. Third Isomorphism Theorem for Modules.

    Let \(R\) be a ring, \(M\) a left \(R\)-module and \(K\subseteq N\subseteq M\) with \(N,K\) submodules of \(M\text{.}\) Then \(N/K\) is a submodule of \(M/K\) and
    \begin{equation*} (M/K)/(N/K)\cong M/N. \end{equation*}
    🔗
    🔗

    22.B.

    Here are some neat examples of modules of homomorphisms. Each has its own directions.
    🔗
    1. Let \(R\) be a commutative ring and \(M,N\) be \(R\)-modules. Show that the set
      \begin{equation*} \operatorname{Hom}_{R}(M,N)=\{\varphi:M\to N\mid\varphi\text{ is an }R\text{-module homomorphism}\} \end{equation*}
      is an \(R\)-module.
      🔗
      🔗
    2. Let \(R\) be a commutative ring and \(M\) an \(R\)-module. Prove that the set
      \begin{equation*} \operatorname{End}_{R}(M)=\{\varphi:M\to M\mid\varphi\text{ is an }R\text{-module homomorphism}\} \end{equation*}
      is a (typically non-commutative) ring with identity under regular the operations of function addition and composition. Some things to think about: what’s the identity element? can you find examples where this ring is non-commutative? commutative?
      🔗
      🔗
    3. From the previous exercise, note that the set of \(R\)-module homomorphisms from \(R\) to itself, i.e. \(\operatorname{End}_{R}(R)\text{,}\) forms a ring. Could we have used ring homomorphisms instead? That is, is the set \(\{\varphi:R\to R\mid\varphi\text{ is a ring homomorphism}\}\) a ring?
      🔗
